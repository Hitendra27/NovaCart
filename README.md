# 📱 NovaCart — Android E-Commerce App (Jetpack Compose)

A modern Android e-commerce application built using **MVVM + Clean Architecture + Jetpack Compose + Hilt + Retrofit**.  
This project demonstrates scalable architecture, reactive UI, and production-ready Android development practices.

---

# 🚀 Features

- 🛍️ Product listing (API powered)  
- 🔍 Search products  
- 📄 Product detail screen  
- ❤️ Wishlist   
- 🛒 Cart system  
- 🌐 REST API integration  
- 🎨 Modern Jetpack Compose UI  
- 🌙 Dark mode support   
- ⚡ Fast and responsive UI  
- 📦 Clean architecture (MVVM)

---

# 🏗️ Tech Stack

- Kotlin  
- Jetpack Compose  
- MVVM Architecture  
- Clean Architecture  
- Hilt (Dependency Injection)  
- Retrofit (Networking)  
- Coroutines & Flow  
- StateFlow  
- Coil (Image loading)  
- Material 3  

---

# 📦 Architecture

```plaintext
UI (Compose)
   ↓
ViewModel
   ↓
Repository
   ↓
Remote Data Source (Retrofit)
   ↓
DummyJSON API
```
